# kit 基础库接口文档

## 1. errors

| API | 说明 |
|---|---|
| `Wrap(code, msg string, cause error) error` | 包装错误并附加错误码 |
| `LogError(code, msg string, cause error) error` | 记录日志并返回包装错误 |
| `GetCode(err error) string` | 获取错误码 |
| `IsNotFound(err error) bool` | 判断是否为未找到错误 |
| `IsTimeout(err error) bool` | 判断是否为超时错误 |
| `IsConnect(err error) bool` | 判断是否为连接错误，支持识别连接类错误码 |

## 2. log

| API | 说明 |
|---|---|
| `InitLogger(cfg *Config) error` | 初始化全局日志，只允许成功初始化一次；nil 配置返回 `ErrNilConfig` |
| `Sync() error` | 同步日志缓冲 |
| `WithFields(fields Fields) *SugaredEntry` | 创建结构化日志入口 |
| `WithContext(ctx context.Context) *SugaredEntry` | 从上下文中提取 `request_id`、`trace_id` |
| `SetGlobalFields(fields Fields)` | 设置全局日志字段，建议仅在启动阶段调用 |
| `Infof/Warnf/Errorf/Debugf` | 基础日志输出 |

说明：重复调用 `InitLogger` 会返回 `ErrLoggerInitialized`；已初始化后，普通日志方法不会覆盖当前 logger。`log.Config.Format` 控制最终输出编码格式，支持 `json` 和 `console`。

## 3. http

| API | 说明 |
|---|---|
| `NewGin(cfg ServerConfig) *gin.Engine` | 创建带默认中间件的 Gin 引擎 |
| `NewServer(cfg ServerConfig) (*Server, error)` | 创建并启动 HTTP Server |
| `Shutdown(ctx context.Context) error` | 优雅关闭服务 |
| `RequestIDMiddleware() gin.HandlerFunc` | 生成或透传 `X-Request-ID` |
| `AccessLogMiddleware() gin.HandlerFunc` | 采集访问日志字段，并通过 `log.WithFields` 输出结构化日志 |
| `ErrorHandler() gin.HandlerFunc` | 统一处理 Gin 错误；响应已写入时只记录日志，不重复写 JSON |
| `TimeoutMiddleware(timeout time.Duration) gin.HandlerFunc` | 为请求注入超时 Context，并在处理完成后按需返回 408 |

注意：当前 `NewServer` 会立即监听端口，建议调用方尽量在启动前完成路由注册；后续版本会考虑拆分创建和启动流程。`ServerConfig.AccessLogFormat` 已废弃，仅保留兼容；HTTP 访问日志最终格式由 `log.Config.Format` 控制。

## 4. sql

| API | 说明 |
|---|---|
| `Connect(dbConfig *Config) (*DB, error)` | 创建数据库连接，nil 配置返回参数错误 |
| `TransactCallback(fn func(*sqlx.Tx) error, tx ...*sqlx.Tx) error` | 执行事务回调 |
| `TransactCallbackCtx(ctx context.Context, fn func(*sqlx.Tx) error, tx ...*sqlx.Tx) error` | 执行带 Context 的事务回调 |
| `IsNoRows(err error) bool` | 判断空结果错误 |
| `Stats() sql.DBStats` | 获取连接池状态 |
| `NewPreDB() *PreDB` | 创建懒加载数据库实例 |
| `PreDB.Init(dbConfig *Config) error` | 初始化懒加载数据库 |
| `PreDB.DB() *DB` | 获取已初始化数据库 |

支持驱动：`mysql`、`postgres`、`clickhouse`。PostgreSQL DSN 会使用 URL 安全拼接，避免用户名或密码中的特殊字符破坏连接串。

## 5. redis

| API | 说明 |
|---|---|
| `NewClient(cfg *Config) (*Client, error)` | 使用默认背景 Context 创建 Redis 客户端 |
| `NewClientCtx(ctx context.Context, cfg *Config) (*Client, error)` | 使用调用方 Context 创建 Redis 客户端，nil 参数返回错误 |
| `Get/Set/Delete/Exists` | 基础 Key 操作 |
| `MGet/MSet` | 批量操作 |
| `GetObj/SetObj` | JSON 对象缓存 |
| `GetTTL/Expire` | 过期时间操作 |
| `Incr/IncrBy` | 原子自增 |
| `Scan` | 游标扫描 Key |
| `TryLock` | 获取分布式锁 |
| `Lock.Unlock` | 释放分布式锁，token 不匹配或锁不存在时返回错误 |
| `Lock.Refresh` | 续期分布式锁，token 不匹配或锁不存在时返回错误 |

推荐新代码优先使用 `NewClientCtx`。

## 6. kafka

| API | 说明 |
|---|---|
| `NewKafkaProducer(cfg *Config) (*KafkaProducer, error)` | 创建 Kafka 生产者，nil 配置返回参数错误，默认同步发送 |
| `SendMessage(topic string, key, value []byte) error` | 使用默认背景 Context 发送消息 |
| `SendMessageCtx(ctx context.Context, topic string, key, value []byte) error` | 使用调用方 Context 发送消息 |
| `NewKafkaConsumer(brokers []string, topic string, groupID string) (*KafkaConsumer, error)` | 创建 Kafka 消费者 |
| `ConsumeMessage(ctx context.Context) (<-chan kafka.Message, error)` | 消费消息并返回 channel |
| `Ack(ctx context.Context, msg kafka.Message) error` | 提交消息 offset |
| `Close() error` | 关闭生产者或消费者 |

推荐新代码优先使用 `SendMessageCtx`。Producer 默认使用同步发送，确保错误返回和重试语义可靠。
